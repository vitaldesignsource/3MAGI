The fonts in this folder, and where each file comes from
========================================================

Licence. Every Noto face listed below is licensed under the SIL Open Font
License, Version 1.1. The licence text and the copyright notice of each Noto
project are in OFL.txt, beside this file. The TC-Seraphine family is not a
Noto face. OFL.txt does not cover it, and this file does not record it.

Provenance. Each file is either a COPY, byte for byte, of one script subset
from a @fontsource package (checked with cmp), or a CUT made from such
subsets by the script named in its entry. The packages were fetched with
`npm pack <package>@5.3.0` and unpacked. They were never installed, so they
are not in package.json or the lockfile for these files. The 12 @fontsource
entries in package.json record the older faces only.

The @font-face rules and their unicode-range lines are in src/index.css. Every
family is named in both script stacks there: `.edu-page .edu-glyph` and
`--edu-script-faces`.

TLSigns.woff2  "TL Signs"  (3,540 bytes, 34 code points)
    Made by tools/fonts/build-tlsigns.py (Python 3.11, fontTools 4.67.0,
    brotli 1.2.0). The script is in the repository, and a rebuild with those
    versions gives the same bytes. It takes:
      33 code points from @fontsource/noto-sans-symbols@5.3.0,
         files/noto-sans-symbols-symbols-400-normal.woff2
         (Noto Sans Symbols, Version 2.003);
       1 code point, U+2609 SUN, from @fontsource/noto-sans-symbols-2@5.3.0,
         files/noto-sans-symbols-2-symbols-400-normal.woff2
         (Noto Sans Symbols 2, Version 2.008). Noto Sans Symbols has no Sun.
    The script merges them into one font. It keeps every outline and advance
    unchanged, and it checks them against the sources. It drops what single
    signs do not need: hinting, layout tables and vertical-writing metrics.
    It sets the line metrics to Noto Sans's own 1069 / -293, the same as
    TLRunic. Every sign's ink lies within y -222..765. Noto Sans Symbols'
    own 1480 / -570 would open up any line of prose that quotes a sign. The
    font is renamed "TL Signs", and its copyright notice is kept.

    The code points are exactly the Unicode-encoded units of the Signs of
    the Art (the planets, the zodiac, and the alchemical elements,
    principles, substances and operations):
      planets     U+2609 SUN, U+263D FIRST QUARTER MOON, U+263F MERCURY,
                  U+2640 FEMALE SIGN (Venus), U+2642 MALE SIGN (Mars),
                  U+2643 JUPITER, U+2644 SATURN
      zodiac      U+2648 ARIES .. U+2653 PISCES (twelve)
      elements    U+1F701 AIR, U+1F702 FIRE, U+1F703 EARTH, U+1F704 WATER
      principles  U+1F70D SULFUR, U+263F MERCURY, U+1F714 SALT
      substances  U+2641 EARTH (antimony), U+1F716 VITRIOL,
                  U+1F739 SAL-AMMONIAC, U+1F705 AQUAFORTIS, U+1F706 AQUA REGIA
      operations  U+1F75E SUBLIMATION, U+1F75F PRECIPITATE, U+1F760 DISTILL,
                  U+1F764 PUTREFACTION
    The @font-face unicode-range names these and nothing else. If the signs
    module gains a sign, add it to the script and to that unicode-range,
    rebuild, and update this entry.
