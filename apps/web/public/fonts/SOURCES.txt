The fonts in this folder, and where each file comes from
========================================================

Licence. Every face listed below is licensed under the SIL Open Font
License, Version 1.1: the Noto faces, and the faces made from Cinzel. The
licence text and the copyright notice of each project are in OFL.txt, beside
this file. The TC-Seraphine family is not listed here. OFL.txt does not cover
it, and this file does not record it.

Provenance. Each file is either a COPY, byte for byte, of one script subset
from a @fontsource package (checked with cmp), or a CUT made from such
subsets by the script named in its entry. The packages were fetched with
`npm pack <package>@5.3.0` and unpacked. They were never installed, so they
are not in package.json or the lockfile for these files. The 12 @fontsource
entries in package.json record the older faces only.

The @font-face rules and their unicode-range lines are in src/index.css. Every
script family is named in both script stacks there: `.edu-page .edu-glyph` and
`--edu-script-faces`. The Cinzel supplement is the exception: its five files
are declared as more faces of the "Cinzel" family, so they are named wherever
Cinzel is, and in neither script stack. The faces of scripts that have no
italic (TL Hebrew, TL Arabic, TL Phoenician, TL Runic, TL Ogham, TL Signs) are
declared a second time with font-style: italic and the same file, so that
text set in an italic note stands upright instead of being slanted by the
browser.

TLSigns.woff2  "TL Signs"  (3,540 bytes, 34 code points)
    Made by tools/fonts/build-tlsigns.py (Python 3.11, fontTools 4.67.0,
    brotli 1.2.0). The script is in the repository, and a rebuild with those
    versions gives the same bytes. It takes:
      33 code points from @fontsource/noto-sans-symbols@5.3.0,
         files/noto-sans-symbols-symbols-400-normal.woff2
         (Noto Sans Symbols, Version 2.003);
       1 code point, U+2609 SUN, from @fontsource/noto-sans-symbols-2@5.3.0,
         files/noto-sans-symbols-2-symbols-400-normal.woff2
         (Noto Sans Symbols 2, Version 2.008). Noto Sans Symbols has no Sun.
    The script merges them into one font. It keeps every outline and advance
    unchanged, and it checks them against the sources. It drops what single
    signs do not need: hinting, layout tables and vertical-writing metrics.
    It sets the line metrics to Noto Sans's own 1069 / -293, the same as
    TLRunic. Every sign's ink lies within y -222..765. Noto Sans Symbols'
    own 1480 / -570 would open up any line of prose that quotes a sign. The
    font is renamed "TL Signs", and its copyright notice is kept.

    The code points are exactly the Unicode-encoded units of the Signs of
    the Art (the planets, the zodiac, and the alchemical elements,
    principles, substances and operations):
      planets     U+2609 SUN, U+263D FIRST QUARTER MOON, U+263F MERCURY,
                  U+2640 FEMALE SIGN (Venus), U+2642 MALE SIGN (Mars),
                  U+2643 JUPITER, U+2644 SATURN
      zodiac      U+2648 ARIES .. U+2653 PISCES (twelve)
      elements    U+1F701 AIR, U+1F702 FIRE, U+1F703 EARTH, U+1F704 WATER
      principles  U+1F70D SULFUR, U+263F MERCURY, U+1F714 SALT
      substances  U+2641 EARTH (antimony), U+1F716 VITRIOL,
                  U+1F739 SAL-AMMONIAC, U+1F705 AQUAFORTIS, U+1F706 AQUA REGIA
      operations  U+1F75E SUBLIMATION, U+1F75F PRECIPITATE, U+1F760 DISTILL,
                  U+1F764 PUTREFACTION
    The @font-face unicode-range names these and nothing else. If the signs
    module gains a sign, add it to the script and to that unicode-range,
    rebuild, and update this entry.

TLDisplayMarks-400.woff2, -500, -600, -700, -800  "Cinzel" (font-weight 400 ..
    800; the name inside the files is "TL Display Marks")
    (3,144 / 3,244 / 3,296 / 3,312 / 3,348 bytes, 24 code points each)
    Made by tools/fonts/build-display-marks.py (Python 3.11, fontTools 4.67.0,
    skia-pathops 0.9.2, brotli 1.2.0). The script is in the repository, and a
    rebuild with those versions gives the same bytes. For each weight it reads
    two files of @fontsource/cinzel@5.3.0 (tarball sha1
    9fca0f01e58b7a07fdf1a853ac44ef2a3102e0d7):
      files/cinzel-latin-{w}-normal.woff2 and
      files/cinzel-latin-ext-{w}-normal.woff2
      (Cinzel, Version 2.000: the static instances of the variable font that
      Google Fonts serves; at 400 their outlines are identical to it, at 500 ..
      800 within one font unit).
    The code points are the letters and signs the site sets in Cinzel and
    Cinzel lacks: U+1E0C-1E0D, U+1E24-1E25, U+1E32-1E33, U+1E36-1E37,
    U+1E5A-1E5B, U+1E62-1E63, U+1E6C-1E6D, U+1E92-1E93 (D H K L R S T Z with
    dot below, capital and small), U+02BE-02BF (the half rings ʾ ʿ), U+02BC
    (ʼ), U+01EA-01EB (Ǫ ǫ), U+2116 (№), U+2190 and U+2192 (← →). Nothing is
    drawn by hand. The dotted letters are composites of Cinzel's own letter
    and the dot of its Ż ż, set below the letter as far as that dot stands
    above z. ʾ and ʿ are the two halves of Cinzel's ring (U+02DA), cut on its
    vertical axis and set where quoteright sits. ʼ is quoteright. Ǫ ǫ take the
    ogonek of Ę ę, placed as Ę places it. № is N with Cinzel's o reduced and
    raised, over a reduced en dash. ← and → are Cinzel's en dash, lengthened,
    with a reduced single guillemet as the head. The script checks that every
    outline it reuses equals the source glyph's point for point, that the two
    half rings make up the ring, and that overlapping parts do not cancel.
    The files keep Cinzel's line metrics (976 / -372), have no hinting and no
    layout tables, and keep Cinzel's copyright notice with "Modified 2026,
    Three Magi Press." added. Cinzel's licence reserves no font name; the
    files are renamed all the same, as a modified version should be.
    The unicode-range of the five @font-face rules names these code points and
    nothing else. To add one, add it to the script and to that unicode-range,
    rebuild, and update this entry.
